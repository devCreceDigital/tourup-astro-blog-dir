# Second Brain

A personal knowledge base for the TourUp project — a place to store notes, research, decisions, and reference material that doesn't belong in the main codebase.

## Structure

- `notes/` — Quick notes and ideas
- `research/` — Research findings and external references
- `decisions/` — Architecture and design decisions (ADRs)
- `reference/` — Reference docs, links, and snippets
- `inbox/` — Unprocessed items waiting to be organized
